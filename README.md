# Precision, Recall, and F1 Score

In-depth analysis of classification evaluation metrics beyond accuracy, with practical examples on imbalanced datasets.

## Topics Covered

- Confusion matrix breakdown
- Precision vs. Recall trade-off
- F1 Score and when to use it over accuracy
- ROC curve and AUC
- Practical example with an imbalanced dataset

## Tech Stack

Python, Scikit-learn, NumPy, Pandas, Matplotlib

## Run

```bash
pip install scikit-learn numpy pandas matplotlib jupyter
jupyter notebook precision_recall_f1.ipynb
```
